# AudioCityStudio-
Audio City Studio Android Audio Production App

## Apps in this repository

- `CityStudioAndroid/`: Audio City Studio, the Android audio production app.
- `CityCinemaAndroid/`: City Cinema, a standalone manual cinema video camera (Camera2, 10-bit HLG, log looks, scopes, double-system audio). See `CityCinemaAndroid/README.md`.
